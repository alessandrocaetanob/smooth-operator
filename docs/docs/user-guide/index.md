# User Guide Overview

This guide covers everything a regular user needs to know to get the most out of Smooth Operator.

## Navigation

The sidebar on the left gives you access to all areas of the application:

| Item | Description |
|------|-------------|
| **My Access** | All connections you can launch, grouped by vault |
| **My Vaults** | Card-based view of your vaults and their connections |
| **Help** | Opens this documentation (you're here!) |
| **Sign Out** | Log out of the application |

Admins and TeamAdmins see additional items: Connections, Known Hosts, Credentials, and Settings.

## User roles

Your role determines what you can see and do:

| Role | Access |
|------|--------|
| **User** | Launch sessions in assigned vaults, manage your own profile |
| **TeamAdmin** | Everything a User can do + manage connections in assigned vaults |
| **Admin** | Full access except Owner-only settings |
| **Owner** | Complete access to all features and settings |
